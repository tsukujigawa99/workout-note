# 仕様書 07：記録写真のデザイン切替（ノーマル／かわいい／おしゃれ／かっこいい）

- 作成: PM（2026-10-10）　／　宛先: 開発担当・テスト担当
- 版: v1.3.0 で追加。前提は `docs/06_仕様_記録写真.md`（現行の合成＝「ノーマル」）
- 見本: 依頼者提供の 3 枚（PM が scratchpad に `sample_cute.png`／`sample_chic.png`／`sample_cool.png` として渡す）。既存の白カード＝ノーマルの見本は `sample_result.png`。

## 1. 方針

- 合成の流れ（読み込み → 縮小 → 合成 → toBlob → 共有/保存）、純粋関数 `fitPlan`／`photoText`、写真を外に出さない原則は 06 のまま。**描き方だけをテーマ（デザイン）ごとに差し替える**。
- 4 テーマ: `normal`（ノーマル＝現行）, `cute`（かわいい）, `chic`（おしゃれ）, `cool`（かっこいい）。
- 見本に「近づける」のが目的。イラスト（くま等）は再現不要。文字・線・図形（ハート・星・王冠・スマイル・ダンベルの簡単な線画）だけで雰囲気を出す。写真の人物をなるべく隠さない。
- 追加フォントは Google Fonts のみ（外部ライブラリ禁止は変わらず）。**起動時には読み込まず**、記録写真のシートを初めて開いた時に 2 本目の `<link rel="stylesheet">` を動的に追加する（起動の重さを増やさない。sw.js は fonts.googleapis.com／fonts.gstatic.com を実行時キャッシュするので 2 回目以降はオフラインでも使える）。
- フォント取得待ちは最大 **5 秒**（初回は和文サブセットのダウンロードが要るため 06 の 2 秒から延長）。超えたらシステムフォントで描く。
- 見本画像の文言（「今日もがんばった」「継続は最強」「Keep Going」等）は装飾の定型文として固定で入れてよい。個人を特定する内容は入れない。

## 2. 画面（シート）の変更

- オプションを 2 段にする:
  1. `デザイン`（1 列・`.seg` 4 ボタン）: `ノーマル` / `かわいい` / `おしゃれ` / `かっこいい`。`data-act="photoTheme" data-arg="normal|cute|chic|cool"`。320px 幅でも 4 ボタンの文言が 1 行に収まること（このセグだけ `font-size:11px` 可）。
  2. 既存の 3 列: `位置`（左/右）／`カード`（白/黒）／`反転`（なし/あり）。**`カード` はノーマル以外では無効**（`disabled` にして薄く表示。非表示にはしない＝レイアウトが跳ねない）。
- 既定: 前回使ったデザインと位置を端末に記憶（`localStorage['won-photo']` に `{ theme, pos }`、同期しない。読めなければ normal／right）。反転とカードは記憶しない（毎回 なし／白）。
- デザイン切替時は再合成（位置・反転と同じ流れ。File を作り直し、完了まで保存ボタンを無効）。切替先テーマのフォントが未読込なら、プレビュー上に「フォントを読み込んでいます…」を重ねて（または `.empty` に差し替えて）読み込み後に描く。

## 3. 共通の描画ルール（全テーマ）

- 寸法は 06 と同じ基準（`u = min(W,H)/1080`、パネル幅 `P`、余白 `m`、位置 左/右、反転は写真のみ）。
- カードの高さ計算は 06 の `CARD` 寸法・`fitPlan` を**全テーマで共用**する（テーマで変えるのは見た目だけ）。ただしテーマごとに「見出しの高さ `headerH`」と「下部の装飾に確保する高さ `bottomReserve`」を持ち、`fitPlan` の `avail = H − カード開始 y − bottomReserve − m` とする。
- 文字間隔（`WORKOUT LOG` のような英字の字間）は `ctx.letterSpacing` が使えない環境のため、1 文字ずつ描く補助関数で実装する。
- 「他 N 種目」の扱いは 06 と同じ（テーマの文字色で）。
- 種目名がはみ出す時の `…` 省略、RM 表記（`RM : 57.50kg` または `RM 57.50kg`）、セット行の桁揃え（番号／重量右揃え／×／reps／補助）は全テーマ共通の読みやすさを守る。

## 4. テーマ別の見た目

### 4.1 normal（ノーマル）
- 現行どおり（06 の 4.3〜4.4）。白／黒カード切替あり。

### 4.2 cute（かわいい）
- フォント: 本文・数字 `Zen Maru Gothic`（500/700）、手書き風の飾り文字 `Yomogi`（400）。
- 写真はそのまま（明るいパステル調にするため、全体に `rgba(255,255,255,.08)` を薄く重ねてよい）。
- 見出し: 日付 `2026.10.08（木）` を `Yomogi 60px` 濃紺 `#2F3A56`。文字の下に太さ 10px のピンク `rgba(255,150,180,.55)` のマーカー線（手書き風に少し傾けてよい）。周りに小さなハート（ピンク `#FF8FB1`）と 4 つ星のきらめき（白・濃紺）を 3〜5 個。
- カード: 白 `rgba(255,255,255,.92)`、角丸 22px、柔らかい影（`shadowBlur 16, rgba(0,0,0,.12)`）。見出し行は種目名の背景にパステルの帯（高さ 34px、角丸、色は順に `#FFD6E3`（ピンク）→ `#D6E8FF`（水色）→ `#FFF1B8`（黄）→ `#E6D9FF`（紫）の繰り返し）、その左に小さなダンベル線画（濃紺）。種目名 `Zen Maru Gothic 700 26px` 濃紺。RM は `Zen Maru Gothic 500 18px` グレー `#7A7A8C`。
- セット行: `Zen Maru Gothic 500 26px` 濃紺。
- カード右側の空き（セット行の右）に手書きの一言を `Yomogi 22px` 濃紺で: 先頭カードは `部位名 + '\nがんばった!!'`（部位名は `partOf(exOf(ex).part).name`。取れなければ「がんばった!!」のみ）、2 枚目以降は `['パンプ\n最高♡','効いた!!','最後まで\nやりきった!']` を順に。**scale が 0.8 未満、またはセット数が 1 の時は描かない**（窮屈になるため）。一言の近くに王冠（黄 `#F5C542`）かスマイル（線画）を 1 つ。
- 周辺の飾り（パネルと反対側）: 上 `今日も\nがんばった ☺`（Yomogi 30px、白地の角丸ラベル `rgba(255,255,255,.85)` の上に濃紺文字）、中ほど `Better\nMe♡`（Yomogi 28px 白＋影）、下 水色ラベル `rgba(214,232,255,.9)` に `☑ 水をのむ\n☑ たんぱく質とる\n☑ ゆっくり寝る`（Yomogi 22px 濃紺）。パネル側の下に `継続は\n最強`（Yomogi 40px 濃紺、白縁取り）＋王冠、`また明日も\nがんばろう ☺`（Yomogi 22px）。
- `bottomReserve = 0.16 × H`。

### 4.3 chic（おしゃれ）
- フォント: 英字・数字の見出し `Cormorant Garamond`（500/600）、和文 `Noto Serif JP`（500）、筆記体 `Great Vibes`（400）、セット行は `Noto Sans JP 400`（細め・見本どおり）。
- 写真: 全体を少し暗く・暖色に（`rgba(20,16,12,.28)` を全面、パネル側は横グラデーションで `rgba(0,0,0,.45)` まで）。
- 見出し: `WORKOUT LOG`（Cormorant 500 22px、字間 0.35em、白 80%）→ 日付 `2026/10/08`（Cormorant 600 96px 白）→ 太さ 1px の白線（幅 P）→ `（木）今日`（Noto Serif JP 500 24px 白）。
- カード: 塗りなし。上下に太さ 1px の白線（`rgba(255,255,255,.55)`）。見出し行: 円（半径 16px、線 1px 白）に通し番号 `01`（Cormorant 500 20px 白）→ 種目名（Noto Serif JP 500 28px 白）→ 右端 `RM 57.50kg`（Cormorant 500 20px 白 85%）。
- セット行: Noto Sans JP 400 24px 白。
- 周辺の飾り: 左上 `Better\nThan\nYesterday`（Great Vibes 56px 白、少し右上がりに回転 −6°）。左下 `SMALL\nSTEPS\nBIG\nCHANGES`（Cormorant 500 22px、字間 0.3em、白 85%、1 行ずつ）。右下 `Keep\nTraining`（Great Vibes 64px 白）＋ `今日の積み重ねが、\n明日の自分をつくる。`（Noto Serif JP 500 22px 白、右揃え）。位置＝左の時は左右を入れ替える。
- `bottomReserve = 0.17 × H`。

### 4.4 cool（かっこいい）
- フォント: 日付・数字 `Oswald`（400/500/700、既存）、ブラシ文字 `Permanent Marker`（400）、和文 `Noto Sans JP 700`（既存）。
- 写真: 全体にビネット（四隅を `rgba(0,0,0,.5)` へ）＋パネル側に縦長の黒い帯（横グラデーション `rgba(0,0,0,.55)`）。右上の角に斜めのダークグレー `#2a2a2a` のストライプを 2〜3 本（見本の右上）。
- 見出し: 日付 `2026/10/08`（Oswald 700 92px 白、`ctx.transform` で −8° のスキュー）＋ `（木）今日`（Noto Sans JP 500 26px 白）。下に `TRAINING RECORD`（Oswald 400 18px、字間 0.4em、白 85%）と左右の短い白線。
- カード: 塗り `rgba(0,0,0,.55)`、線 1.5px 白 85%、**右上と左下の角を 18px 斜めに切る**（六角形）。見出し行: 白い平行四辺形マーク（幅 14px・高さ 22px、−15° スラント）→ 種目名（Noto Sans JP 700 26px 白）→ 右端に RM の丸いピル（塗り `rgba(255,255,255,.18)`、`RM : 57.50kg` Oswald 500 18px 白）。
- セット行: Oswald 400 26px 白（重量は `45.0kg` のように kg を詰めてよい）。
- 周辺の飾り: 左上 `NO PAIN\nNO GAIN`（Oswald 400 20px 字間 0.3em 白 80%）。左下 `Keep\nGoing`（Permanent Marker 84px 白、−8° 回転、影）。右下 `BETTER THAN YESTERDAY`（Oswald 400 18px 字間 0.3em 白 85%、両脇に線）。位置＝左の時は左右を入れ替える。
- `bottomReserve = 0.18 × H`。

## 5. 実装の形

- 新規 `app/js/photo-themes.js`: `export const THEMES = { normal:{…}, cute:{…}, chic:{…}, cool:{…} }`。各テーマは
  `{ label, fonts: [[cssFont, sampleTextKind], …], headerH(u), bottomReserve(H), drawBackdrop(ctx, g), drawHeader(ctx, g), drawCard(ctx, g, item, i, y, h, scale), drawDecor(ctx, g) }`
  （`g` = `{ W, H, u, P, x0, pos, m, text, style }` などの共有情報）。`fonts` の `sampleTextKind` は `'num'`（数字・英字）／`'ja'`（和文）で、06 の `loadFonts` が実文字列を渡す仕組みをテーマごとに使う。
- `app/js/photo.js`: `compose()` を「写真 → `drawBackdrop` → `drawHeader` → カード（fitPlan は共通）→ 他 N 種目 → `drawDecor`」の順にテーマへ委譲。`normal` の描画は現行コードを `photo-themes.js` へ移す。フォントの 2 本目 `<link>` の追加（`id="won-photo-fonts"`、1 回だけ）。`localStorage['won-photo']` の読み書き（try/catch）。
- Google Fonts の URL（1 本）: `https://fonts.googleapis.com/css2?family=Zen+Maru+Gothic:wght@500;700&family=Yomogi&family=Cormorant+Garamond:wght@500;600&family=Noto+Serif+JP:wght@500&family=Great+Vibes&family=Permanent+Marker&display=swap`
- `app/css/app.css`: `.photo-opts` の上に `.photo-theme`（1 列の `.seg`、`font-size:11px`）を追加。`.seg button:disabled{opacity:.4;cursor:default}` を追加（既存 `.seg` のルールは変えない）。
- `app/sw.js`: `CACHE_VERSION 'v1.3.0'`、SHELL に `js/photo-themes.js`。`app/js/defaults.js`: `APP_VERSION '1.3.0'`。
- `tests/test.html`: バージョン検査を 1.3.0・SHELL 検査に `js/photo-themes.js`。`photo-themes.js` を import し、4 テーマに `label` と 6 つの関数があること、`headerH`／`bottomReserve` が正の数、`fonts` が空でないこと、ラベルが「ノーマル／かわいい／おしゃれ／かっこいい」であることをテスト（描画はテスト不要）。`fitPlan` に `bottomReserve` を引いた avail を渡しても仕様どおり動くこと（既存テストで担保）。

## 6. 受け入れ基準

1. 自動テスト全件 PASS。
2. シートに「デザイン」4 ボタンが出て、切替で見本に近い見た目に変わる（4 テーマ×位置 左/右 のスクリーンショットを見本と見比べる）。
3. ノーマル以外では「カード 白/黒」が無効表示になり、ノーマルに戻すと有効に戻る。
4. 反転・位置が全テーマで効き、飾り文字は反転しない。位置＝左で飾りが左右入れ替わる。
5. 種目が多い日（10 種目）に全テーマで写真からはみ出さない（縮小→「他 N 種目」）。下部の飾りと重ならない。
6. 初回のフォント読み込み中もアプリが固まらず、5 秒以内に描画される（オフラインではシステムフォントで描ける）。起動時の `<link>` は増えていない（index.html は変更しない）。
7. デザインと位置が次回のシートで記憶されている。
8. 320px／375px／PC 幅で崩れない。赤／黒テーマで崩れない。
9. 既存のノーマル描画が v1.2.1 と同じ（変わっていない）。
10. `won-days` 等の記録データに変化がない。写真はどこにも残らない。
