# 仕様書 09：3 テーマ化（サンセット／ゴールド／グリーン）v2.1.0

- 作成: PM（2026-10-14）　／　宛先: 開発担当・テスト担当
- 背景: 依頼者が参考画像 3 種で確定（`mock/ref_v3/home_sunset.png`、`mock/ref_v3/home_gold_green.png` の左＝ゴールド、右＝グリーン）。v2.0.0（docs/08）の赤／ブルーを置き換え、**この 3 つをテーマとして切り替えられる**ようにする。**機能・操作・データは一切変えない**。
- 3 枚は配置が共通なので、**レイアウトは 1 つ**、テーマは配色トークンと「上部の空の描き方」だけを差し替える。

## 1. テーマの定義

| id | 名前（設定画面） | 雰囲気 | 既定 |
|---|---|---|---|
| `sunset` | サンセット | 夕焼けの上部＋濃紺の地。カレンダー・リング・履歴は白い紙カード、日付・集計は暗い半透明カード。主ボタンはピンク→オレンジ | ○ |
| `gold` | ゴールド | 夜景の上部＋濃紺の地。すべて暗いカード、金色のアクセント。主ボタンは金のグラデーション（文字は濃紺） | |
| `green` | グリーン | 明るい朝の上部＋淡い緑白の地。白いカード、緑のアクセント。主ボタンは緑のグラデーション | |

- 保存キー `won-skin` はそのまま。**旧値の読み替え**: `red`→`sunset`、`black`／`blue`→`gold`。不明な値→`sunset`。読み替えは `app/js/defaults.js` に `SKINS = ['sunset','gold','green']` と `normalizeSkin(v)` を置き、`main.js`・`index.html` の初期化スクリプト（ここは関数を import できないので同じ対応表を直書き）・`settings.js` で使う。
- ホーム右上のテーマボタン: タップで `sunset → gold → green → sunset` と巡回。設定画面の「テーマ」行: タップでシート（既存 `sheet()`）を開き 3 つから選ぶ（選択中にチェック）。値表示は上の名前。
- `theme-color` meta: sunset／gold＝`#101729`、green＝`#DCE7D6`。manifest の `theme_color`／`background_color` は `#101729`。
- iOS のステータスバーは `black-translucent`（白文字）で固定のため、**グリーンの上部は最上段（safe-area 分＋40px）を少し濃い緑のグラデーションにして白文字が読めるようにする**。

## 2. 上部の「空」（ヘッダー背景）

- 写真素材は無いので CSS グラデーションで描く（画像ファイルは追加しない）。高さはヘッダー＋日付／リング行の中ほどまで（約 260px、スマホ）。下端は地の色へなめらかに溶かす。
- sunset: 上は濃い青紫、右上に暖色の太陽のにじみ（radial-gradient、オレンジ→透明）、下へ向かって濃紺 `--ground` に溶ける。
- gold: 上は黒に近い紺、右上に金色のにじみ（控えめ）、下へ濃紺へ。
- green: 上は白に近い淡緑、右上に白い光のにじみ、下へ `--ground`（淡緑白）へ。最上段だけ濃い緑（1 章の注記）。
- ヘッダー: 左にダンベルアイコン（既存 `bell`）＋「WorkOut Note」（Oswald 600 26px）＋タグライン「今日の積み重ねが、明日の自分をつくる。」。右に丸いアイコンボタン 2 つ（テーマ巡回＝`skin`、設定＝`tab settings`。アイコンは既存の `skin`／`set`）。参考画像の筆記体「Better Than Yesterday」は入れない。

### カレンダーのセル
- 記録あり＝`--cal-on`（sunset: ピンク `#F27A96`、gold: 金 `#E3B04B`、green: 若草 `#8FBF7F`）の塗り＋文字は `--cal-on-ink`（sunset: 白、gold: 濃紺、green: 濃緑）。
- 今日＝`--cal-today`（sunset: 黒 `#1A1A1A`、gold: 金 `#F0C75E` の塗り＋濃紺文字、green: 濃緑 `#2F5A33`）の塗り＋白（gold は濃紺）文字。今日が記録ありでも「今日」の色を優先。
- 選択日（今日以外）＝セルの外側に 2px のアクセント色のリング。
- 記録なし＝`--cal-off`（薄いグレー）の丸。他の月＝文字だけ薄く。
- `pickDay`／aria はそのまま。

### レイアウト幅
- **380px 以上**: 参考画像どおり 2 列（左 52%／右 48%、間 10px、外側余白 14px）。カレンダーのセルは幅に合わせて縮む（最小 20px、文字 13px）。
- **380px 未満**（320px 等）: 1 列（日付 → リング → カレンダー → 集計 3 枚）。横スクロールなし。
- 600px 以上: 2 列のまま、最大幅 760px。960px 以上: 920px 中央カラム。

## 7. 追補（v2.1.1）: 上部の背景写真

- 依頼者から背景写真が提供された（サンセット用: `app/img/bg-sunset.jpg`、幅 1080px・上部 900px・JPEG 約 80KB。PM が配置済み）。ゴールド用（青い夕暮れ）・グリーン用（明るい窓辺）の写真は後続で `app/img/bg-gold.jpg`／`app/img/bg-green.jpg` として追加予定。
- 実装: 上部の空（`.home::before` 等）に `background-image` で写真を敷き、その上に **テーマごとの色の被せ**（下端は `--ground` へ溶ける縦グラデーション、サンセットは薄い濃紺の被せ、ゴールドは濃い紺の被せで暗く、グリーンは最上段の濃い緑の帯はそのまま）を重ねる。写真は `background-size: cover; background-position: center top`。高さは現行の空と同じ。
- 写真ファイルは **テーマごとに CSS の `:root[data-skin=…]` で指定**（`--sky-img: url(../img/bg-sunset.jpg)`）。ファイルが無いテーマ（当面ゴールド・グリーン）は `--sky-img: none` でグラデーションのまま。ゴールドは当面サンセットの写真を濃い紺の被せで暗くして使う（依頼者の写真が届き次第差し替え）。
- `app/sw.js` の SHELL に `img/bg-sunset.jpg` を追加（オフラインでも表示）。`CACHE_VERSION 'v2.1.1'`、`APP_VERSION '2.1.1'`、tests の版検査更新と SHELL 検査に `img/bg-sunset.jpg`。
- 受け入れ: サンセット／ゴールドの上部に写真が出て、ヘッダーの文字（白）が読める。カードは写真の上に重なり、空の下端が地の色に自然に溶ける。グリーンは従来どおり。320／390／430／1024px で崩れない。

## 8. 追補（v2.1.3）: 上部の写真が見切れる（iPhone 実機の指摘）

- 依頼者の iPhone 実機（グリーン、2026-10-14）: 上部の写真が、ステータスバー対策の濃い緑の帯（safe-area 分＋フェード）と、すぐ下から始まるカード行に挟まれて、右上のボトル・タオルがわずかに覗くだけになっている。参考画像では写真が上部の約 300px を占め、ヘッダー文字の下に写真の被写体が見えてからカードが始まる。
- 対処:
  1. **ヘッダー領域を高くする**: `.htop`（ヘッダー＝ロゴ・タイトル・タグライン・丸ボタン）の下に写真が見える余白を確保し、最初のカード行が **コンテンツ上端から約 200px**（safe-area を除く）で始まるようにする。写真の箱（`.home::before`）の高さは `300px + safe-t` のままとし、下端約 100px のフェード部分にカード行が重なる形にする（参考画像と同じ比率）。600px 以上・960px 以上も同じ考え方。
  2. **グリーンの最上段の帯を軽くする**: 濃い緑のベタ塗りをやめ、safe-area の範囲だけ `rgba(79,122,72,.72)` 程度の半透明にし、その下 24px で透明へ。写真が透けて見え、白いステータスバー文字のコントラストは 3:1 以上を保つ。サンセット／ゴールドは帯なし（写真が暗いので不要）。
  3. **写真の位置**: `background-position: center top` のまま（被写体が上部にある素材のため）。被写体が丸ボタンの背後に来るのは参考画像と同じ構図なので可。
  4. ログイン案内カードが出る時は、写真の見える余白の下（ヘッダー領域の後）に置く。
- 確認方法: 内蔵ブラウザでは safe-area が 0 のため、`document.documentElement.style.setProperty('--safe-t','59px')` で iPhone 相当を模擬して 3 テーマ × 390／430px を確認。実機の見え方は依頼者確認。
- 版: `APP_VERSION '2.1.3'`、`CACHE_VERSION 'v2.1.3'`、tests の版検査更新。
- 受け入れ: 3 テーマで、ヘッダー文字の下に写真の被写体（ボトル・ダンベル／タオル）が見えてからカードが始まる。グリーンの帯が薄く、写真が透ける。320／390／430／1024px で崩れない。
