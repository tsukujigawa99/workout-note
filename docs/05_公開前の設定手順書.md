# 公開前の設定手順書（ご本人作業・約5分）

同期と公開のために、コンソールでの設定が3つ必要です。いずれもログインが必要なためご本人にお願いします。

---

## 1. Firestore のセキュリティルールを貼る（本人しか読み書きできないようにする）

1. https://console.firebase.google.com/ → プロジェクト `workout-note` →「構築」→「Firestore Database」→ 上部の「**ルール**」タブ。
2. 表示されている内容を**すべて消して**、下をそのまま貼り付け →「**公開**」。

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```

意味：「ログインしている本人の `users/本人ID/` 以下だけ読み書きできる。それ以外は全て拒否」。

## 2. ログインを許可するサイトに公開URLを追加

1. 同じ Firebase コンソール →「構築」→「Authentication」→「**設定**」タブ →「**承認済みドメイン**」。
2. 「ドメインを追加」→ `tsukujigawa99.github.io` を入力 → 追加。
   （`localhost` は最初から入っているので、PCのローカル確認はこの設定なしでもログインできます）

## 3. GitHub Pages の公開方法を設定

※ こちらからの初回アップロード（push）の後に行います。push の際に GitHub のログイン画面がブラウザで開いたら、ご本人がログインしてください。

1. https://github.com/tsukujigawa99/workout-note →「**Settings**」→ 左メニュー「**Pages**」。
2. 「Build and deployment」の **Source** を「**GitHub Actions**」に変更（保存ボタンは無く、選ぶだけで反映）。
3. 上部「**Actions**」タブ →「Deploy to GitHub Pages」→ 右の「**Run workflow**」→ 緑の「Run workflow」。1〜2分で緑のチェックになれば公開完了。
4. 公開URL：**https://tsukujigawa99.github.io/workout-note/**

---

## 4. iPhone での初回セットアップ

1. **Safari** で上の公開URLを開く。
2. 画面の「Googleでログイン」→ Firebase を作ったのと同じ Google アカウントでログイン。
3. 共有ボタン（□に↑）→「**ホーム画面に追加**」。
4. ホーム画面の「WorkOut Note」アイコンから起動。
   - アイコンから起動したアプリ内で再度ログインを求められた場合は、そこでもう一度ログインしてください（Safari とホーム画面アプリはログイン情報が別管理のため）。
   - うまくログインできない場合は、表示されたメッセージ（またはスクリーンショット）を教えてください。
