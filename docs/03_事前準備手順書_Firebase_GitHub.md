# 事前準備手順書（ご本人作業）— Firebase と GitHub

同期機能（フェーズ2）と公開（フェーズ3）のために、**アカウント作成とログインが必要な部分だけ**ご本人にお願いします。
所要時間の目安：合計 15〜20 分。費用は 0 円です（クレジットカード登録は不要。求められたら進まずに止めてください）。

※ 画面の文言は時期により多少変わることがあります。迷ったらスクリーンショットを送ってください。

---

## A. Firebase（データ保存・同期・ログイン）

### A-1. プロジェクト作成
1. https://console.firebase.google.com/ を開き、**個人の Google アカウント**でログイン（会社アカウントではなく、iPhoneでも使う個人のものを推奨）。
2. 「プロジェクトを作成」→ プロジェクト名 `workout-note` → 続行。
3. Google アナリティクスは **オフ** で OK → 「プロジェクトを作成」。
4. 料金プランが **Spark（無料）** になっていることを確認（左下に表示）。

### A-2. ログイン機能（Authentication）
1. 左メニュー「構築」→「Authentication」→「始める」。
2. 「ログイン方法」タブ →「Google」→ **有効にする** → サポートメールに自分のアドレスを選択 → 保存。

### A-3. データベース（Firestore）
1. 左メニュー「構築」→「Firestore Database」→「データベースの作成」。
2. ロケーション：`asia-northeast1 (Tokyo)` を選択（**後から変更不可**）。
3. 「**本番環境モード**で開始」を選択 → 作成。
   - セキュリティルール（本人しか読み書きできない設定）は、後でこちらから貼り付け用のテキストをお渡しします。

### A-4. ウェブアプリの登録と設定値の取得
1. プロジェクトの概要（家のアイコン）→ 「アプリを追加」→ **ウェブ（`</>`）**。
2. アプリのニックネーム `WorkOut Note` →「Firebase Hosting も設定する」は **チェックしない** → 登録。
3. 表示される `const firebaseConfig = { apiKey: "...", authDomain: "...", projectId: "...", ... };` の **{ } の中身をコピーして、このチャットに貼り付けてください**。
   - この値は「アプリの宛先情報」で、パスワードや秘密鍵ではありません（Webアプリでは公開される前提の値です）。データの保護はログイン＋セキュリティルールで行います。

---

## B. GitHub（アプリの公開場所）

1. https://github.com/ でアカウント作成（既にあればログイン）。
2. 右上「＋」→「New repository」。
   - Repository name：`workout-note`
   - **Public** を選択（無料プランで GitHub Pages を使うため。公開されるのはアプリのプログラムだけで、トレーニング記録は含まれません）
   - 他はそのまま →「Create repository」。
3. 作成後に表示されるリポジトリのURL（例：`https://github.com/<ユーザー名>/workout-note`）を **このチャットに教えてください**。
4. このPCからの初回アップロード時に、GitHub のログイン画面（ブラウザ）が開きます。その時はご本人がログイン操作をしてください（パスワードをこちらに伝える必要はありません）。

## D. 公開後に iPhone で行うこと（フェーズ3で改めてご案内）

1. Safari で公開URL（`https://<ユーザー名>.github.io/workout-note/`）を開く。
2. 共有ボタン →「ホーム画面に追加」。
3. ホーム画面のアイコンから起動 → Google でログイン。
